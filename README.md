# Restaurant Ordering System (Frontend)

Modern restaurant ordering system web application built with **Vue 3**, **Vite**, **Vue Router**, and **Tailwind CSS**.

## 📁 Quick Folder Overview

| Directory | Purpose |
| :--- | :--- |
| `src/assets/` | Static media, logos, and global icons |
| `src/components/` | Reusable UI components (`base/`, `layout/`, `ui/`) |
| `src/composables/` | Vue 3 composition functions (reusable reactive logic) |
| `src/layouts/` | Shell layouts (CustomerLayout, AdminLayout, AuthLayout) |
| `src/modules/` | Feature-specific business modules (orders, menu, tables) |
| `src/pages/` | Routed pages (`home/`, `preview/`, `dashboard/`, `auth/`) |
| `src/router/` | Vue Router configuration and route guards |
| `src/services/` | Backend API integration & HTTP clients |
| `src/stores/` | Pinia global state stores (cart, auth, orders) |

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```
